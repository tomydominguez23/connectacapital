# Connecta Capital – sitio web + Conecta Capital Brokers

Maqueta navegable desarrollada por Trust Motors SpA para Asesorías e Inversiones Connecta SpA.

| Página | Archivo |
|---|---|
| Sitio web público (buscador, comparador, calculadora) | `index.html` |
| Ficha de proyecto: Casa Bustamante | `proyecto.html` |
| Recorrido 3D del departamento | `recorrido-3d.html` |
| Marketplace de proyectos (Brokers) | `brokers.html` |
| CRM y leads | `crm.html` |
| Automatizaciones WhatsApp y correo | `automatizaciones.html` |
| Panel del dueño | `admin.html` |

Es HTML estático, sin backend ni instalación: basta abrir `index.html`.

- Los leads, vendedores y métricas del CRM y del panel son datos de ejemplo, y los botones de envío no mandan mensajes reales.
- Los modelos 3D son ilustrativos: calzan con la superficie publicada por tipología, pero la distribución y las medidas se reemplazan con los planos de cada inmobiliaria.
- Proyectos, precios y fotos provienen de connectacapital.cl y están sujetos a confirmación de cada inmobiliaria.

Para publicarlo con GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
